 ## Le choix du type de navigation
Dans mon site, j’ai utilisé une navigation mixte. Quand on est sur la page d’accueil et qu’on clique sur un lien du menu comme À propos, Projets ou Contact, on ne change pas de page. Le site descend directement à la section correspondante sur la même page. Quand on clique sur un des projets dans la section Projets, certains projets s’ouvrent dans un modal, tandis qu’un projet ouvre une nouvelle page. On quitte donc la page d’accueil uniquement pour ce dernier projet.
